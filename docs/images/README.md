# Bedrock screenshots

These images are actual native x86-64 QEMU captures from the menu and installer
verification workflows. They are copied here unchanged so the project README
renders in a fresh checkout without generated or ignored build artifacts.

- `desktop.png`: Files and Notes with independent native windows.
- `control-center.png`: Files, the system bar and Control Center.
- `installer.png`: drive partition review before erase confirmation.

`screenshots.json` records each original capture path, verification receipt,
scene and SHA-256. Each copied PNG matches its passed receipt and original PPM
pixels. The capture workflows are documented in
[menu verification](../system-menus-verification.md) and
[installer verification](../installer-verification.md).
